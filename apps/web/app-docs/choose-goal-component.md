# ChooseGoal

Самостоятельная декоративная иллюстрация. Экран и API пока не подключены.

```tsx
import { ChooseGoal } from "@/modules/career-plan";

<ChooseGoal />
// Статичная версия:
<ChooseGoal animated={false} />
```

Родитель показывает компонент только после успешной загрузки плана без цели,
рядом с локализованным текстом «Укажите карьерную цель» и действием перехода
к форме. При наличии цели, загрузке или ошибке API иллюстрация не нужна.
Не заменяет warnings и пояснение для Lead без следующего грейда.

Ассет: public/animations/choose-goal.json; статичная замена: choose-goal.svg.
360 × 240, 30 fps, 60 кадров (2 секунды), прозрачный фон, без повторения.
Ширина 140 px на mobile и 180 px на desktop. После проигрывания остаётся
незавершённый маршрут с двумя ответвлениями и тремя ориентирами: кругом,
ромбом и кольцом. Контур возможной цели собирается из двух золотых дуг.
Ориентиры появляются последовательно; они не обозначают завершённые активности.
Последние кадры неподвижны. JSON содержит только векторные слои, бюджет — 40 КБ.
Повторный монтаж компонента запускает анимацию снова; обычный rerender — нет.

Обёртка загружает плеер только при разрешённом движении. Reduced motion,
animated=false и ошибка загрузки оставляют SVG. Иллюстрация aria-hidden;
текст и CTA принадлежат родителю и не зависят от анимации. Место зарезервировано
до загрузки, SVG присутствует в серверной разметке.

Storybook: Career Quest/ChooseGoal → Animated и Static.
Reduced motion проверяется системной настройкой или эмуляцией браузера.

Происхождение: оригинальная векторная композиция создана AI-агентом по
утверждённому брифу пользователя; сторонние изображения и шрифты не использованы.
Цвета взяты из app-docs/ui-system-map.md. Плеер — установленный lottie-react
3.1.2 (MIT), https://github.com/Gamote/lottie-react; новые зависимости не добавлены.
Это не назначает лицензию всему проекту.
