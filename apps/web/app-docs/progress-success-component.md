# ProgressSuccess

Самостоятельный компонент подтверждения завершения активности.
Пока не подключён к экрану или mutation; это ассет, компонент и Storybook.

```tsx
import { ProgressSuccess } from "@/modules/activities";

<ProgressSuccess />
<ProgressSuccess animated={false} />
```

Три сегмента собираются в кольцо, затем появляется галочка.
360 × 240, прозрачный фон, 30 fps, 45 кадров (1,5 секунды), без повторения.
Последние 10 кадров — неподвижный результат. Ширина компонента 96 px.
Ассеты: public/animations/progress-success.json и progress-success.svg.
Бюджет JSON — до 40 КБ; только вектор, без шрифтов и растров.

Родитель запускает анимацию только после успешного API-ответа завершения,
если already_completed=false. При already_completed=true — не показывать
или передать animated=false. Не запускать при загрузке, ошибке или просто
открытии истории. Не использовать одновременно с другой смысловой Lottie.
Фактические изменения навыков и готовности выводятся родителем из API,
анимация не рассчитывает и не обещает прирост.

Общая обёртка LottieAnimation обеспечивает lazy loading, aria-hidden,
фиксированные пропорции, статичную SVG-замену при reduced motion и ошибках.
Текст результата остаётся доступным независимо от иллюстрации.
Повторный монтаж запускает анимацию снова; обычный rerender — нет.

Storybook: Career Quest/ProgressSuccess — Animated, Static, InContext,
AlreadyCompleted. Значения навыков в InContext — только демонстрационные.

Происхождение: оригинальная векторная композиция AI-агента по утверждённой
пользователем идее; палитра из app-docs/ui-system-map.md. Сторонние ассеты
не использованы. Установленный lottie-react 3.1.2 — MIT:
https://github.com/Gamote/lottie-react. Новых зависимостей нет.
Это не назначает лицензию всему проекту.
