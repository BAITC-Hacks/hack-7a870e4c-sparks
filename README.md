# Career Quest — Sparks

Прототип для кейса 1 Career Quest, трек Halyk Bank, HackAlem AI. Помогает сотруднику понять, каких навыков не хватает для выбранной роли и грейда, и выбрать подходящее обучение. HR получает сводку дефицитов и может загрузить дополнительные синтетические профили и историю для проверки.

Реализованы профиль и карьерная цель, план развития с прогнозом навыков, до трех объяснимых рекомендаций, чат с карьерным консультантом, подтверждение завершения обучения и HR-импорт JSON/CSV. Сотрудник имеет доступ только к собственным данным; публичных рейтингов результативности нет.

## Архитектура

Elysia API на Bun/TypeScript отвечает за сессии, права сотрудник/HR, профили, импорт и сохранение данных в PostgreSQL через Prisma. Он передает контекст выбранного сотрудника Python-агенту на FastAPI. Агент строит план, рассчитывает допустимые шаги и обращается к OpenAI Responses API со Structured Outputs. Только агент получает ключ OpenAI. При недоступности модели он продолжает подбор по правилам; при недоступности самого агента API сохраняет расчетные рекомендации, а план и чат возвращают 503.

## Запуск одной командой

Нужны работающий Docker с Compose и `openssl`. Из корня репозитория:

```bash
./init.sh
```

Скрипт создаст недостающие локальные пароли в `.env`, соберет и запустит PostgreSQL, Python-агент и API, дождется готовности и на macOS откроет [Swagger](http://localhost:3001/api/docs). Вариант без открытия браузера: `./init.sh --no-open`. Порт API по умолчанию — 3001; изменить его можно через `API_PORT`. Остановка: `docker compose down`; данные PostgreSQL сохраняются.

Для AI-подбора добавьте `OPENAI_API_KEY` в корневой `.env`; при необходимости задайте `OPENAI_MODEL` (в Compose по умолчанию `gpt-4.1-mini`) и повторите запуск. Без ключа доступен расчетный режим. Настройки описаны в [.env.example](.env.example); секреты не нужно добавлять в Git.

## Сценарий проверки

1. Откройте `GET /api/health` в Swagger. При доступном агенте без ключа ожидаются `status: "ok"`, `agent_available: true`, `ai_configured: false`.
2. Войдите через `POST /api/auth/login` сотрудником `E0005` с паролем `DEMO_EMPLOYEE_PASSWORD` из локального `.env`. Загрузите профиль, карьерный план и рекомендации; задайте вопрос консультанту.
3. Подтвердите выполнение допустимого рекомендованного мероприятия и повторно загрузите профиль и план. Навыки пересчитываются по сохраненной истории, повторное подтверждение не добавляет прирост второй раз.
4. Войдите как `hr` с паролем `HR_PASSWORD`, откройте сводку и импортируйте [примеры жюри](examples/jury/). Проверьте новый профиль.

Точные маршруты, тела запросов, локальный запуск без Docker и команды проверок: [README API](apps/api/README.md). Формат контекста, логика подбора и запуск FastAPI: [README агента](apps/agent/README.md). Контракт для интеграции: [OpenAPI JSON](apps/api/openapi.json).

## Данные и ограничения

Источник — предоставленный [синтетический датасет Career Quest](case_1/career_quest_dataset/README.ru.md); дата расчета берется из `meta.as_of_date` (`2026-10-01`). Данные разрешены только для хакатона; реальные персональные данные использовать нельзя. Прирост учитывается только при известном `completed_at` строго после дня последней оценки и не позже даты среза. Обязательные мероприятия сохраняются в истории, но не рекомендуются. Покрытие навыков не означает гарантированное повышение; подтверждение выполнения демонстрационное, без LMS-интеграции.

В `apps/web` реализованы вход, профиль, карьерная цель, рекомендации и завершение активности с фактическим результатом до/после. Frontend запускается отдельно; команды и автоматическая проверка с перехватом HTTP описаны в [README frontend](apps/web/README.md). Карьерный план, чат, HR-view и импорт пока доступны только через API. Compose поднимает серверную часть и Swagger. Живой сквозной сценарий интерфейса, ответы OpenAI и публичное развертывание этими проверками не подтверждены. Публичная ссылка пока не предоставлена.

Подробнее: [политика данных](docs/data-policy.md) и [контракт API](docs/api-contract.md).
